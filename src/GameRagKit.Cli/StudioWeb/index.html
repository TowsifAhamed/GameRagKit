GameRagKit

Give every NPC a real mind, backed by your own lore.

GameRagKit is a retrieval-augmented persona engine for game NPCs: drop your world, region, and faction lore into files, declare a persona in YAML, and get an NPC that answers in character, remembers what it's told, and can share personality context with hundreds of others through the same hierarchy, all through one small HTTP API (/ask) any engine or client can call.

Hear what a GPU would add

The NPCs in these demos speak with Kokoro, a small open voice model that runs on the CPU server hosting this site. The same lines below, generated with two larger open models, carry real emotion: laughs, sighs, voices designed from a one-line character description. They need a GPU to keep up in a live conversation, and we can’t afford to host one for this demo. On a gaming PC with a modern GPU, GameRagKit can run them locally, and your NPCs would sound like this.
